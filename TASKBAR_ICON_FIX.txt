VOICEGUARD TASKBAR ICON — REAL FIX v2

This revision addresses BOTH problems seen in the previous build:
- the Start Menu icon appearing squished
- Windows continuing to use the old pinned taskbar icon

ICON:
- VoiceGuard.ico is generated from a square 1024x1024 transparent master.
- The shield is vertically proportioned and is never stretched from a wide image.
- ICO contains 16, 20, 24, 32, 40, 48, 64, 96, 128, 192 and 256 pixel frames.
- The shell icon is embedded through ApplicationIcon.

WINDOW/TASKBAR:
- WinForms explicitly supplies 256px and 32px icon handles with WM_SETICON.
- The process now has a distinct AppUserModelID:
  JackTheGooner.VoiceGuard.6.5.5
  This prevents Windows from identifying the running application as the old
  pinned VoiceGuard identity.

INSTALLER:
- This revision installs into a new versioned directory:
  Program Files\VoiceGuard\6.5.5
  The executable is still named VoiceGuard.exe.
- Start Menu and desktop shortcuts explicitly use VoiceGuard.exe as their icon.

TEST PROCEDURE:
1. Unpin every existing VoiceGuard icon from the taskbar.
2. Uninstall the previous VoiceGuard installation.
3. Install this revision.
4. Open VoiceGuard from the NEW Start Menu shortcut.
5. Confirm the Start Menu icon is the square transparent shield.
6. While VoiceGuard is running, right-click its NEW taskbar icon and pin it.
7. Close VoiceGuard and launch it again from the pinned icon.

Do not reuse an old pinned VoiceGuard shortcut for this test.

The source is not compiled in this environment because the .NET SDK is not installed here.
The ICO was generated and inspected in this environment.
