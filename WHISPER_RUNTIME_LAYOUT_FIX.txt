VoiceGuard 6.5.5 — Whisper runtime layout correction

Whisper.net.Runtime 1.9.1 publishes its Windows x64 native libraries under:
publish\runtimes\win-x64\

Required CPU runtime files:
  whisper.dll
  ggml-whisper.dll
  ggml-base-whisper.dll
  ggml-cpu-whisper.dll

The previous build script incorrectly checked for whisper.dll in the publish root.
The installer already includes the entire publish directory, so the correct runtime
layout is preserved for Whisper.net's NativeLibraryLoader.
